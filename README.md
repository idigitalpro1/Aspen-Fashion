# Aspen-Fashion

AI-powered fashion intelligence app built with Google AI Studio and Gemini API.

This is the public Aspen Fashion app deployed at:

https://aspen-fashion.vercel.app

## Run Locally

1. Install dependencies:

   ```bash
   npm install
   ```

2. Add a local Gemini key:

   ```bash
   echo "GEMINI_API_KEY=your-key-here" > .env.local
   ```

3. Start the app:

   ```bash
   npm run dev
   ```

4. Open:

   ```text
   http://localhost:3000
   ```

## Build

```bash
npm run build
```
